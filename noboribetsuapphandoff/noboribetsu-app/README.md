# 登別 第二住民票プロトタイプ

北海道登別市向け「第二住民票」構想のプロトタイプ Web アプリです。旅行者・関係人口が
ボランティア参加やクマ見守り通報、畑作業、記念碑への刻銘といった「関わり」を通じて
第二の市民になっていく体験を、1枚の HTML ファイルとして実装しています。

## クイックスタート

ビルドもインストールも不要です。`juminhyo.html` をブラウザで直接開くだけで動作します。

```bash
open juminhyo.html
```

## 主な機能

- ログイン／新規登録（PIN方式、1台の端末で複数アカウント管理可能）
- 未登録ゲストは「お知らせ」タブ（祭り情報など）のみ閲覧可能。住民票を発行すると
  ボランティア/バイト情報、クマ見守り、畑、クーポン、記念碑刻銘が解放される
- クマ見守りカメラと連動した X（Twitter）風のアプリ内タイムライン「けもみちタイムライン」
  （通報すると自動でタイムラインに投稿される）
- 5言語対応（日本語・英語・韓国語・中国語・トルコ語、初回訪問時はブラウザ言語を自動判定）
- 独自ポイント通貨「とむコイン」
  - 累計獲得とむコイン（ランクを決める、減らない）
  - 使用可能とむコイン（クーポン交換・種代に使う、減る）
- 温泉・飲食店クーポンの交換
- 畑機能（種代を払って植える → 水やりで成長 → 収穫時に発送先フォームが開き注文が作られる）

## ファイル

- `juminhyo.html` — アプリ本体（正本）
- `juminhyo-v2.html` — `juminhyo.html` の複製（別URLでの公開用に維持しています）
- `CLAUDE.md` — Claude Code でこのプロジェクトを編集する際の技術メモ
  （データ構造、i18nの仕組み、関数一覧、開発時の注意点など）

## 開発を続ける方へ

技術的な詳細（データ構造、i18nアーキテクチャ、翻訳の仕組み、既知の懸念事項など）は
すべて `CLAUDE.md` にまとめてあります。Claude Code でこのフォルダを開いて作業を
始める場合、まず `CLAUDE.md` を読み込ませてください。

## 注意事項

これはプロトタイプです。認証・データ保存はすべてブラウザの `localStorage`内で
完結しており、実際のサーバーやデータベースは存在しません。本番運用にはサーバー
サイドの実装が別途必要です。
